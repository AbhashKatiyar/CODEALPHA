🌐 Language Translation Tool

A modern and user-friendly Language Translation Tool developed using Python as part of my Artificial Intelligence & Machine Learning Internship at CodeAlpha.

This application enables users to translate text seamlessly between multiple languages through an intuitive graphical user interface. It leverages translation APIs to provide fast and accurate translations while offering additional features that enhance the overall user experience.

## ✨ Features

- 🌍 Translate text between 10 languages
- 🔍 Automatic language detection
- 🖥️ Clean and responsive graphical user interface (GUI)
- 📋 Copy translated text to clipboard
- 🔄 Swap source and target languages
- 🗑️ Clear input and output with a single click
- ⚡ Fast and accurate translations 
- 🛡️ Input validation and exception handling
- 📱 Beginner-friendly and easy-to-use interface

## 🛠️ Technologies Used

- Python 3
- CustomTkinter / Tkinter
- Google Translator API (deep-translator / googletrans)
- pyperclip
- Threading
- Object-Oriented Programming (OOP)
