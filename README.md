#🚀 CodeAlpha Artificial Intelligence & Machine Learning Internship

Welcome to my CodeAlpha Internship Repository!

This repository contains all the projects I successfully completed during my Artificial Intelligence & Machine Learning Internship at CodeAlpha. Throughout this internship, I worked on real-world AI and Machine Learning applications using Python, gaining hands-on experience in Natural Language Processing (NLP), Computer Vision, API Integration, and Desktop Application Development.

Each project demonstrates practical problem-solving skills, clean coding practices, and the implementation of AI concepts in real-world scenarios.

## 📂 Projects

### 🌐 1. Language Translation Tool
A modern desktop application that translates text between multiple languages using translation APIs. The application features an intuitive graphical interface, automatic language detection, language selection, copy-to-clipboard functionality, and optional text-to-speech support.

Key Highlights
- Translate between 100+ languages
- Automatic language detection
- User-friendly GUI
- Copy translated text
- Optional Text-to-Speech
- API Integration

Technologies Used
- Python
- Tkinter / CustomTkinter
- Google Translator API
- pyperclip


### 🤖 2. Python FAQ Chatbot
An intelligent chatbot designed to answer frequently asked questions related to Python programming. The chatbot uses Natural Language Processing techniques and a structured FAQ database to provide quick and accurate responses through an interactive GUI.

Key Highlights
- Python programming FAQ assistant
- Interactive chatbot interface
- NLP-based question matching
- Expandable FAQ database
- Beginner-friendly GUI

Technologies Used
- Python
- Tkinter / CustomTkinter
- JSON
- NLP
- Fuzzy String Matching
- Regular Expressions


### 🎯 3. Object Detection and Tracking System
A real-time Computer Vision application capable of detecting and tracking multiple everyday objects using a webcam or video feed. Built with YOLO and OpenCV, the system identifies objects, displays confidence scores, and tracks movement across video frames.

Key Highlights
- Real-time object detection
- Multiple object tracking
- YOLO-based deep learning model
- Bounding boxes with confidence scores
- Live webcam/video processing

Technologies Used
- Python
- OpenCV
- YOLO (Ultralytics)
- NumPy
- Computer Vision
- Deep Learning
