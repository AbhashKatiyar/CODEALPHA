🤖 Python FAQ Chatbot

A simple yet intelligent Python FAQ Chatbot developed using Python as part of my Artificial Intelligence & Machine Learning Internship at CodeAlpha.

This chatbot is designed to answer frequently asked questions related to the Python programming language through an interactive graphical user interface. It uses Natural Language Processing (NLP) techniques such as text preprocessing and similarity matching to understand user queries and provide accurate, predefined responses in real time.

## ✨ Features

- 💬 Interactive and user-friendly chatbot interface
- 🐍 Answers frequently asked questions about Python programming
- 🔍 Intelligent keyword and similarity-based question matching
- ⚡ Instant responses with minimal latency
- 📚 Easily expandable FAQ database
- 🎨 Modern graphical user interface (GUI)
- 🛡️ Handles unknown or unsupported questions gracefully
- 🔄 Continuous conversation support until user exits
- 📝 Clean and organized code structure

## 🛠️ Technologies Used

- Python 3
- Tkinter / CustomTkinter
- Natural Language Processing (NLP)
- Fuzzy String Matching
- Regular Expressions (Regex)
- Object-Oriented Programming (OOP)
