🎯 Object Detection and Tracking System

A real-time Object Detection and Tracking System developed using Python as part of my Artificial Intelligence & Machine Learning Internship at CodeAlpha.

This project utilizes Computer Vision and Deep Learning techniques to detect, classify, and track multiple objects in real-time through a webcam or video input. Powered by the YOLO (You Only Look Once) object detection model and OpenCV, the system identifies everyday objects with high accuracy, draws bounding boxes, tracks their movement across frames, and displays confidence scores to provide an intelligent visual monitoring solution.

## ✨ Features

- 🎥 Real-time object detection using webcam
- 🎯 Multiple object detection and tracking simultaneously
- 📦 Bounding boxes with object labels and confidence scores
- 🚶 Real-time object tracking across video frames
- ⚡ High-speed inference using the YOLO model
- 🖥️ Live video processing with OpenCV
- 🔍 Supports detection of common day-to-day objects
- 📊 Displays FPS (Frames Per Second) for performance monitoring
- 🛡️ Graceful handling of unknown or unsupported objects
- 📝 Clean, modular, and well-documented code structure
